# Работа над VANTAGE

Перед изменениями прочитайте `README.md`, `docs/product-decisions.md`, `docs/development-plan.md` и текущий макет в `design/`. Эти файлы фиксируют решения, согласованные с владельцем проекта. Общайтесь с пользователем по-русски.

## Цель

Построить мобильный веб прототип простого каршеринга легковых автомобилей с визуальным стилем премиального сервиса VANTAGE. Прототип затем станет основой для учебной практики и архитектурной курсовой. Пользователь хочет сначала разработать продукт, а по готовой реализации подготовить учебные материалы.

## Правила продукта, которые уже согласованы

- Бронирование доступного автомобиля только «сейчас», без будущей даты. На начало аренды дается 20 бесплатных минут; бронь можно отменить, по истечении она отменяется автоматически.
- При бронировании клиент выбирает режим: на заранее выбранный срок с более низким тарифом или без фиксированного срока. Досрочное завершение первого режима не уменьшает цену выбранного периода; время сверх него оплачивается по обычному тарифу. Во втором режиме оплачивается фактическое время. Километраж не учитывается.
- Один клиент может иметь не более одного забронированного или арендованного автомобиля. Машину нельзя одновременно выдать двум клиентам.
- Завершение аренды разрешено в любой точке внутри отдельной зоны Иркутска. В первой версии клиент сам указывает точку на карте. Реальные GPS, замки и платежи не подключаются; кнопка «Оплатить» меняет статус.
- Первая регистрация только по имени. Для будущего Telegram Mini App предусмотрены необязательные поля телефона, тега и числового Telegram ID. Панель администратора не входит в первую версию.

## Интерфейс и реализация

- Главный экран утвержден как визуальный ориентир: темная карта на весь телефон, серебристые акценты, нижняя карточка автомобиля, логотип VANTAGE, название машины шрифтом Roboto. Не возвращайте удаленные элементы: верхнюю плашку «ИРКУТСК», отдельную подпись зоны, кнопку геолокации, счетчик «01 / 02», стрелку в кнопке бронирования.
- В карточке есть кнопка «ФОТО» справа от названия автомобиля; она открывает изображение поверх экрана. Текущее изображение — демонстрационное и не соответствует достоверно указанной модели.
- Планируемый стек: React + TypeScript, Node.js + TypeScript, PostgreSQL, React Leaflet + OpenStreetMap, Docker Compose. Оставляйте источник картографических тайлов заменяемым и показывайте требуемое указание авторства OpenStreetMap.
- Границы зоны, цены и точный коэффициент ускорения времени еще не утверждены. Держите их настраиваемыми и фиксируйте выбранные значения перед реализацией зависимых функций.

После согласованных изменений обновляйте `docs/product-decisions.md` и при необходимости `docs/development-plan.md`, чтобы следующий агент не восстанавливал решения по истории чата. Не называйте интерактивный макет готовым приложением.
