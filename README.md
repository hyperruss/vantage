# VANTAGE

VANTAGE — учебный прототип каршеринга легковых автомобилей в Иркутске. Один продукт предназначен для учебной практики по теме «Каршеринг легковых автомобилей» и курсовой по теме «Создание архитектуры и прототипа системы управления арендой транспортных средств (каршеринг)».

## Состояние проекта

В приложении можно пройти путь от регистрации по имени до итога поездки. Профиль, вход, автопарк, бронирование и расчет стоимости работают через API на Node.js и PostgreSQL. Сервер удерживает машину до отмены, истечения брони или завершения поездки, сохраняет итоговую стоимость и время условной оплаты. Интерактивный HTML в `design/` хранит утвержденный визуальный ориентир для главного экрана.

## Локальный запуск

Запустите Docker Desktop или Docker Engine с плагином Compose. В PowerShell из корня проекта выполните:

```powershell
Copy-Item .env.example .env
docker compose up --build --wait
```

В Bash используйте `cp .env.example .env`. Копирование нужно только при первом запуске. Если порт 3000 уже занят, измените `APP_PORT` в `.env` и используйте выбранный порт в адресах ниже.

- [http://localhost:3000](http://localhost:3000) — клиент VANTAGE.
- [Проверка API](http://localhost:3000/api/health) — возвращает `{"status":"ok"}`, когда API может читать таблицу автомобилей.
- [Список автомобилей](http://localhost:3000/api/cars) — возвращает автомобили из PostgreSQL. На новой базе в списке три автомобиля.
- [Сессия](http://localhost:3000/api/session) — возвращает текущего пользователя по cookie. При первом входе клиент отправляет имя на тот же адрес методом `POST`.
- [Настройки карты](http://localhost:3000/api/map) — источник тайлов, указание авторства и текущий контур зоны.

При старте сервер автоматически применяет еще не выполненные SQL миграции из `db/migrations/`. Миграции создают и заполняют каталог автомобилей и добавляют таблицы пользователей, сессий и бронирований. Команда `docker compose down` останавливает проект, сохраняя данные в томе PostgreSQL.

Для смены подложки укажите `MAP_TILE_URL`, `MAP_TILE_ATTRIBUTION` и `MAP_TILE_ATTRIBUTION_URL` в `.env`, затем примените конфигурацию командой `docker compose up -d`. Для настройки контура `MAP_ZONE` принимает JSON с парами `[широта, долгота]`. По умолчанию используются [публичные тайлы OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/) и временный контур центральной части Иркутска.

Ставки по умолчанию составляют 599 ₽ в час для режима «На срок» и 13 ₽ в минуту для режима «По факту». Чтобы изменить ставки для новых броней, укажите `FIXED_HOUR_KOPECKS` и `METERED_MINUTE_KOPECKS` в копейках в `.env`, затем выполните `docker compose up -d`. Действующая бронь сохраняет ставки, которые действовали при ее создании.

Чтобы проверить общую бронь, откройте VANTAGE в обычном и приватном окнах. Зарегистрируйтесь в обоих. Забронируйте машину в первом и убедитесь, что в открытом втором окне ее метка исчезает после обновления каталога. Отмените бронь в первом, чтобы увидеть возврат метки во втором.

Чтобы проверить условную оплату, начните поездку из действующей брони и завершите ее внутри контура на карте. Нажмите «Оплатить», затем обновите страницу на экране итога. Экран «Поездка оплачена» откроется с той же суммой. Кнопка «На карту» возвращает в каталог.

### Работа с клиентом

С запущенным Compose и установленным Node.js 24 выполните `npm ci`, затем `npm run dev`. Vite откроет клиент на [http://127.0.0.1:5173](http://127.0.0.1:5173) и направит запросы `/api` в Compose. Команды `npm run typecheck` и `npm run build` проверяют типы и собирают оба приложения соответственно.

Клиент находится в `apps/web/`, API — в `apps/api/`. В Compose сервер отдает собранный клиент и API через один порт.

## Ближайшая работа

Добавить настраиваемое ускорение времени и сценарии проверки по плану разработки.

Карта в HTML макете схематичная. В приложении планируется React Leaflet с подложкой OpenStreetMap. Фото автомобиля иллюстративное, поэтому его нельзя выдавать за фотографию конкретного Kia K5.

Публичный репозиторий содержит содержательное изложение листа задания. Оригинальный DOCX с персональными данными студента и преподавателей сюда не загружен.
