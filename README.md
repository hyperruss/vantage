# VANTAGE

VANTAGE — учебный прототип каршеринга легковых автомобилей в Иркутске. Один продукт предназначен для учебной практики по теме «Каршеринг легковых автомобилей» и курсовой по теме «Создание архитектуры и прототипа системы управления арендой транспортных средств (каршеринг)».

## Состояние проекта

На 11 октября 2026 года согласованы правила первой версии и внешний вид главного мобильного экрана. **Код приложения еще не создан.** Интерактивный HTML в `design/` — макет интерфейса, а не готовый сервис.

## Ближайшая работа

1. Спроектировать в той же стилистике экраны регистрации по имени, ожидания брони, активной поездки, завершения аренды и имитации оплаты.
2. Создать основу мобильного веб приложения и серверного API согласно плану.
3. Реализовать первый сквозной сценарий: выбор доступной машины на карте и бронирование.

Карта в HTML макете схематичная. В приложении планируется React Leaflet с подложкой OpenStreetMap. Фото автомобиля иллюстративное, поэтому его нельзя выдавать за фотографию конкретного Kia K5.

Публичный репозиторий содержит содержательное изложение листа задания. Оригинальный DOCX с персональными данными студента и преподавателей сюда не загружен.
