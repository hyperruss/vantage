# Содержание листа задания по курсовой

Это изложение содержательных требований из предоставленного листа задания без персональных данных. Оригинальный DOCX не размещен в публичном репозитории.

**Дисциплина:** Архитектура клиент-серверных приложений.

**Тема:** Создание архитектуры и прототипа системы управления арендой транспортных средств (каршеринг).

**Срок представления к защите:** 9 декабря 2026 года.

## Исходные данные, перечисленные в задании

- Архитектурные стили и паттерны: микросервисная архитектура, API Gateway, MVC.
- Нотации моделирования: UML, DFD, ER.
- Технологии: React, JavaScript/TypeScript, Node.js, GraphQL Schema Language, MongoDB, PostgreSQL.
- Инструменты: IntelliJ IDEA, draw.io, Git, Jenkins, Docker, Kubernetes.

Этот список указан как исходные данные. Задание отдельно требует обосновать выбор технологий; обязательное применение каждого перечисленного инструмента не подтверждено.

## Вопросы, подлежащие разработке

1. Описать предметную область, для которой создается программное обеспечение.
2. Сформировать функциональные и нефункциональные требования.
3. Определить и описать ограничения проекта.
4. Обзором архитектурных стилей выбрать подходящую архитектуру.
5. Разработать набор детализированных архитектурных диаграмм.
6. Описать применимые паттерны проектирования.
7. Обосновать технологии реализации выбранной архитектуры.
8. Разработать MVP приложения и развернуть его в соответствующей инфраструктуре.

Тема учебной практики, сообщенная пользователем: «Каршеринг легковых автомобилей». Отдельного листа задания по практике пока нет.
